# GitInsight — GitHub Profile Analyzer

A sleek, real-time GitHub profile analyzer built with React and Vite.

Live Demo: https://gitinsight-anchal.netlify.app

## Features
- Developer Personality Type badge
- Language breakdown with color bar
- 30-day activity chart
- Top 6 repositories by stars
- Profile stats (repos, followers, stars, forks)
- No auth required — uses public GitHub API

## Tech Stack
- React 18
- Vite 5
- Recharts
- GitHub REST API

## Run Locally
git clone https://github.com/Anchal2000-hue/github-analyzer.git
cd github-analyzer
npm install
npm start
